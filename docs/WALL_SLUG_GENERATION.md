# Wall Slug Generation & Lookup Guide

## Overview

Every politician/candidate in Choseno has a **wall** — a public profile page at `https://www.choseno.com/wall/[wall_slug]`. This guide explains how wall slugs are generated, stored, and looked up.

---

## 1. How Wall Slugs Are Generated

### The Algorithm

Wall slugs are generated by the `buildPoliticianWallSlug()` function in [`src/lib/utils/slugs.ts`](../src/lib/utils/slugs.ts):

```typescript
export function buildPoliticianWallSlug(name?: string | null, role?: string | null): string {
  const base = [name, role].filter(Boolean).join("-");
  return slugifyText(base || "politician");
}

// slugifyText() does:
// 1. Convert to lowercase
// 2. Remove accents/diacritics (ñ → n, é → e)
// 3. Replace non-alphanumeric characters with hyphens
// 4. Trim leading/trailing hyphens
```

### Example: Harry Bains

| Input | Value |
|-------|-------|
| Full Name | Harry Bains |
| Role | Councillor |
| Combined | "Harry Bains-Councillor" |
| **Generated Slug** | **harry-bains-councillor** |
| **Wall URL** | **https://www.choseno.com/wall/harry-bains-councillor** |

### Name-Only Fallback

If only the name is provided (no role), the slug is just the slugified name:

```
buildPoliticianWallSlug("Brenda Locke", "Mayor") → "brenda-locke-mayor"
buildPoliticianWallSlug("Brenda Locke", null)    → "brenda-locke"
buildPoliticianWallSlug(null, "Councillor")      → "councillor"
buildPoliticianWallSlug(null, null)              → "politician"
```

## 2. Where Wall Slugs Are Stored

### Database Table: `politician_profiles`

Every politician has a profile record in the `politician_profiles` table with columns:

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID | Foreign key to `profiles.id` |
| `wall_slug` | TEXT | Nullable; the canonical wall identifier |
| `political_target_role` | TEXT | Role they're seeking (e.g., "Councillor", "Mayor") |
| `target_boundary_name` | TEXT | District/city they represent (e.g., "Surrey") |
| `political_party_id` | INT | Link to political party |
| ... | ... | (avatar, bio, email, phone, etc.) |

### When Is `wall_slug` Set?

The `wall_slug` column is **automatically populated** when:

1. **User signs up as a politician** — via signup flow
2. **Officeholder profile is claimed** — via `/admin/office-holders` claim redemption
3. **Admin manually creates profile** — via admin panel

The slug is generated using `buildPoliticianWallSlug(full_name, political_target_role)` and stored in the database so links remain stable even if the name or role changes later.

## 3. How to Look Up Wall Slugs for Future Outreach

### Option A: Query the Database (Fastest for Bulk Lookups)

Using psql or Supabase Studio:

```sql
SELECT 
  p.full_name,
  pp.political_target_role AS role,
  pp.target_boundary_name AS city,
  pp.wall_slug
FROM profiles p
JOIN politician_profiles pp ON p.id = pp.id
WHERE pp.target_boundary_name = 'Surrey'
ORDER BY pp.political_target_role, p.full_name;
```

### Option B: Use Supabase Client (In Application Code)

```typescript
import { createClient } from "@/lib/supabase/client";

async function getCouncillorWalls(city: string) {
  const supabase = await createClient();
  
  const { data, error } = await supabase
    .from("profiles")
    .select(`
      full_name,
      politician_profiles(
        wall_slug,
        political_target_role,
        target_boundary_name
      )
    `)
    .eq("politician_profiles.target_boundary_name", city);
  
  if (error) console.error(error);
  return data;
}
```

### Option C: Generate the Slug Locally (If Profile Not Yet Created)

If a politician profile doesn't exist yet, you can **predict** the wall slug:

```typescript
import { buildPoliticianWallSlug } from "@/lib/utils/slugs";

// For outreach to someone not yet in the system
const slug = buildPoliticianWallSlug("Harry Bains", "Councillor");
// → "harry-bains-councillor"
```

**Note:** This is a prediction only — until the profile is created, the URL will not resolve.

### Option D: Check URL Directly (Manual Verification)

For any politician, try:
```
https://www.choseno.com/wall/[firstname-lastname-role]
```

If it resolves (loads their profile page), the slug is correct. If it returns a 404, the profile doesn't exist or the slug format is wrong.

## 4. Wall Slug Lookup Script (For Bulk Outreach)

### JavaScript Example: Generate Outreach Emails

```typescript
import { buildPoliticianWallSlug } from "@/lib/utils/slugs";

// From your CSV: bc-municipal-outreach.csv
const councillors = [
  { full_name: "Harry Bains", role: "Councillor", city: "Surrey", email: "harry.bains@surrey.ca" },
  { full_name: "Rob Stutt", role: "Councillor", city: "Surrey", email: "rob.stutt@surrey.ca" },
  // ... more rows
];

const outreachEmails = councillors.map(c => ({
  to: c.email,
  name: c.full_name,
  role: c.role,
  city: c.city,
  wallSlug: buildPoliticianWallSlug(c.full_name, c.role),
  wallUrl: `https://www.choseno.com/wall/${buildPoliticianWallSlug(c.full_name, c.role)}`,
}));

// Output:
// {
//   to: "harry.bains@surrey.ca",
//   name: "Harry Bains",
//   role: "Councillor",
//   city: "Surrey",
//   wallSlug: "harry-bains-councillor",
//   wallUrl: "https://www.choseno.com/wall/harry-bains-councillor"
// }
```

## 6. Troubleshooting

### Wall URL Returns 404

**Possible causes:**

1. **Profile hasn't been created yet** — the name/role combination doesn't exist in `politician_profiles`
2. **Slug case mismatch** — slugs are always lowercase (this shouldn't happen with the function, but if typing manually)
3. **Accents or special characters** — "José" → "jose", "François" → "francois"

**Fix:** Verify the politician exists in the database first:

```sql
SELECT wall_slug FROM politician_profiles 
WHERE id IN (SELECT id FROM profiles WHERE full_name ILIKE '%Harry Bains%');
```

### Slug Changed After Name/Role Update

Wall slugs are stored in the database and do **not** auto-update when a profile is edited. This is intentional — it keeps wall URLs stable for bookmarks and external links.

If a politician's name/role changes in the admin panel, the `wall_slug` column remains the same unless an admin explicitly updates it.

## 7. For Future Integrations

### Export Politicians with Wall Slugs to CSV

Create a reusable export for outreach:

```sql
-- Export all Surrey councillors with wall slugs
COPY (
  SELECT 
    p.full_name,
    pp.political_target_role AS role,
    pp.target_boundary_name AS municipality,
    pp.wall_slug,
    pp.contact_email AS email,
    pp.contact_phone AS phone,
    CONCAT('https://www.choseno.com/wall/', pp.wall_slug) AS wall_url
  FROM profiles p
  JOIN politician_profiles pp ON p.id = pp.id
  WHERE pp.target_boundary_name = 'Surrey'
  ORDER BY pp.political_target_role, p.full_name
) TO '/tmp/surrey-councillors-with-walls.csv' WITH (FORMAT CSV, HEADER TRUE);
```

Save to file, then use in outreach scripts.
